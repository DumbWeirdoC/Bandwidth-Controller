# Bandwidth Controller

Local network bandwidth management tool for Windows OS.

## Overview
Controls device network throughput between 0 and 200 MB/s with KB/s and MB/s scale controls.

## Local Server Port
The application runs on local port: **http://127.0.0.1:9482**

## Instructions
Run BandwidthController.exe located in the dist folder, or start main.py with Python. The web browser will automatically open http://127.0.0.1:9482 once launched.
